# Imura Rally Congratulations

井村俊哉氏を想起させる投資家風キャラクターが, 株価上昇とともに踊って祝福するGSAPアニメーションです.

## Preview

`index.html`をブラウザで開くと, 約8.93秒のショーが自動再生されます.

## Included

- GSAPはrepositoryのnpm dependencyからViteでbundleし, 実行時の外部CDNを必要としません.
- 190枚の紙吹雪, 24本のストリーマー, 72発の花火, 観客, 上昇チャートを実装しています.
- ダンスは, ジャンプ, 腕振り, シャッフル, スピン, 勝利ポーズで構成しています.
- 再生と一時停止を実装しています.
- `prefers-reduced-motion`が有効な環境では自動再生を停止します.
- 表示される台詞は創作であり, 井村俊哉氏本人の画像, 実際の発言, 推薦, 関与を示すものではありません.

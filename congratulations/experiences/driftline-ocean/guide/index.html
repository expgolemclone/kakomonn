Completion reflection · dailyKpiCompleted

Waves, depth, and a finish line.

Stillwater gives a completed due-card session somewhere quiet to land. The water is drawn rather than photographed, the progress is symbolic rather than scored, and scrolling becomes a dive from the bright instant of completion into the deeper calm that follows.

The idea

Completion pages often shout. Stillwater does something gentler: it lets the achievement deepen. Three moves carry the whole experience — a wave system flowing across every section boundary, a scroll descent from the bright surface to the midnight zone, and a pause panel that turns a chosen number of seconds into a personal closing ritual. One coral accent marks the milestone. Everything else is patient, deep blue.

The stack

  • Plain HTML/CSS/JS. The waves are Canvas 2D and the descent is mostly a CSS gradient — a framework would be ballast.
  • GSAP 3.12 + ScrollTrigger (CDN, deferred) for exactly two scrubbed effects: the depth-veil that darkens as you dive, and the hero waves' parallax. Everything else is IntersectionObserver + requestAnimationFrame.
  • Spectral / Inter / IBM Plex Mono — an elegant serif for the water's voice, a workhorse grotesque for reflection, and a mono that makes each depth feel measured.

Signature technique #1 — the wave system

Every wave on the page — the hero water and the four section-boundary dividers — is the same WaveField class pointed at a different canvas. Each band is two summed sines (one long swell plus one short chop, moving in opposite directions), which is the cheapest trick there is for water that never visibly repeats:

const y = mid
  + A * .62 * Math.sin(u / L.l1 * TAU + t * L.s1 + seed)
  + A * .38 * Math.sin(u / L.l2 * TAU - t * L.s2 + seed * 1.7);

The band is built as an open Path2D, cloned and closed to fill the water, and the open copy is stroked with a faint foam line — so crest and body come from one set of points:

const closed = new Path2D(open);
closed.lineTo(w, h); closed.lineTo(0, h); closed.closePath();
ctx.fill(closed);            // the water
if (L.stroke) ctx.stroke(open);  // the foam crest

One shared rAF loop drives all six canvases, but an IntersectionObserver marks which are on screen and only those get drawn. Each divider gets a data-seed so no two flow in phase. With prefers-reduced-motion, the loop never starts — every field is drawn once at a fixed t and the ocean holds still.

Signature technique #2 — the scroll descent

The trick most people would reach for JS to do is pure CSS: the document body's background is one vertical gradient from surface blue to midnight black, so scrolling the page literally is descending through the water column — no JavaScript, no scroll listener, works in every browser ever:

body{
  background:linear-gradient(180deg,
    #0a2a43 0%, #072138 32%, #051b2e 52%,
    #041524 72%, #020a16 100%);
}

JS then adds the instrumentation on top. A fixed mono HUD converts scroll progress into metres and names the zone you're in — the sections are labelled 0 m, 200 m, 400 m … 1000 m to match:

const p = scrollY / (doc.scrollHeight - innerHeight);
const d = Math.round(p * 1000);
hud.textContent = String(d).padStart(4, '0');
zone.textContent = d < 180 ? 'sunlight zone'
                 : d < 860 ? 'twilight zone' : 'midnight zone';

GSAP's ScrollTrigger scrubs one more layer — a fixed radial "veil" whose opacity rises with depth, so the edges of the viewport dim the deeper you go. If GSAP fails to load, a plain scroll listener does the same job; if motion is reduced, the veil stays off entirely.

Signature technique #3 — completion that rides the waves

The progress portrait is a canvas bar chart where the bars flood upward — each stage eases in with a 110 ms stagger, filled with a teal-to-transparent gradient and capped with a 2px foam line, so opening becomes meeting, recall, clearing, and finally done. The pause panel continues the same idea: real radio groups choose a pause length and whether to hold it now or carry it into the next session. An aria-live line makes each reflection audible at the same moment it changes on screen.

Details that matter

  • The pause controls are real form controls. Pause lengths are input type="radio" in a fieldset (arrow keys work), the timing choice is a second radio group styled as a segmented control, and the custom field checks its radio on focus. Reflection text updates via aria-live="polite".
  • Progressive enhancement. A .js class gates every reveal; without scripts the hero shows a static SVG wave, the dividers fall back to CSS gradients, and every word is readable.
  • Reduced motion is a first-class render path. Static single-frame waves, counters and chart at final values, transparency bars at full width, no smooth scroll, no veil.
  • Coral discipline. One bright accent (#ff7a59) reserved for the achieved state and a single claim — celebration feels brighter when the color has room.
  • DPR-capped canvases. All canvases render at min(devicePixelRatio, 2) and resize on a 150 ms debounce.

The work is complete. The page's only job is to keep the next current away long enough for you to feel what you just did.

Return to the moment

There is no task hidden at the bottom of this page. The closing sequence is deliberately simple:

dailyKpiCompleted = true
pause()
breathe()
remember("I carried it to done")

Then return when you are ready. The clear water will still count.

Stillwater is a celebration of one real state: dailyKpiCompleted. Its chart is a symbolic reflection, not a score or a study-history report.

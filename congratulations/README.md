# congratulations

琴葉姉妹をイメージした非公式ファンメイドの祝福ページです.GSAPでタイトル,キャラクター,紙吹雪,背景,称賛メッセージを動かします.

## 実行

```bash
cd congratulations
npm ci
npm start
```

ブラウザーで `http://127.0.0.1:4173` を開きます.

## 検証

```bash
npm run check
npm test
```

`npm test`は静的検査とChromiumを使うE2Eテストを実行します.

Completion celebration · behind the glow

Making completion feel cosmic.

Afterglow gives the dailyKpiCompleted finish a stage worthy of the effort behind it. One HTML file, one stylesheet and one ES module create the experience: a 72,000-star WebGL field carries the feeling, while a small 2D canvas makes the celebration something you can explore.

The idea

Finishing every due card can arrive quietly: one last prompt, one small state change, then an empty queue. Afterglow makes that instant impossible to miss. The background is not a picture of space; it is a depth field you move through. The console lets you sweep a reticle across bright moments, and the echo grid imagines the news travelling around the world. The interface does not ask for more. It gives the finish room to become a feeling.

The stack

  • Plain HTML / CSS / vanilla ES module. No framework. The page is fundamentally text plus two canvases, so a bundler would only add weight.
  • three.js 0.160 (via an import map, dynamic-imported) for the one heavy thing: the particle starfield. Loaded with import('three') inside a try/catch so a CDN miss never breaks the message, console or counters.
  • Newsreader / IBM Plex Sans / IBM Plex Mono — a literary optical serif for the celebratory voice, a neutral grotesque for body, and a mono reserved for coordinates (RA/Dec, Alt/Az, sidereal time) so the sky still feels precise.

Signature technique — an afterglow with depth

The field is a single THREE.Points cloud of ~72k vertices scattered through a deep box volume, drawn with additive blending so overlapping stars bloom. Each star carries its own colour, scale and twinkle phase as buffer attributes:

for (let i = 0; i < COUNT; i++) {
  positions[i*3+0] = (rnd()*2-1) * 1700;
  positions[i*3+1] = (rnd()*2-1) * 1300;
  positions[i*3+2] = -1800 + rnd()*2100;      // deep Z → parallax
  scales[i]  = 0.35 + Math.pow(rnd(), 3) * 2.6; // few big, many tiny
  phases[i]  = rnd() * Math.PI * 2;             // twinkle offset
}

A tiny ShaderMaterial does the rest on the GPU. Point size falls off with distance (so the volume reads as depth, not a flat sheet), twinkle is a sine of time plus each star's phase, and the fragment shader turns every square point into a soft round glow:

// vertex
float tw = 0.55 + 0.45 * sin(uTime * 1.7 + aPhase);
float size = uSize * aScale * (0.55 + 0.7*tw) * uPixelRatio
           * (320.0 / max(-mv.z, 1.0));           // perspective falloff
gl_PointSize = clamp(size, 0.0, 28.0 * uPixelRatio);

// fragment — round, soft-edged star
float d = length(gl_PointCoord - vec2(0.5));
float a = pow(smoothstep(0.5, 0.0, d), 1.7);
gl_FragColor = vec4(vColor, a * (0.55 + 0.45*vTw));

Parallax comes from moving the camera, not the stars: the pointer pans it a little and scroll pushes it down, so near stars slide faster than far ones. The completed day feels larger because the light behaves like a place, not a flat backdrop.

camera.position.x = pointer.x * 120 + Math.sin(t*0.05) * 24;
camera.position.y = -pointer.y * 90 - scrollY * 0.06;
camera.lookAt(0, -scrollY * 0.045, -400);
points.rotation.z = t * 0.006;                    // slow celestial drift

Details that matter

  • The celebration follows a real sky. The console computes local sidereal time from the Julian date and runs the actual horizontal-coordinate transform, so every bright moment drifts with the night: 
    const ha = (lst - raHours) * 15 * DEG;             // hour angle
const alt = asin(sin(dec)*sin(lat) + cos(dec)*cos(lat)*cos(ha));
// az from atan2(...) → then "43.2° NW", "BELOW HORIZON", etc.
  • No borrowed imagery. Every glow is drawn from layered SVG radial gradients, an feTurbulence cloud, and seeded star scatter — procedural, palette-locked, zero image bytes.
  • Two independent rAF loops, both polite. The WebGL field and the 2D console each pause on visibilitychange; the console also pauses when scrolled out of view via IntersectionObserver. Device-pixel-ratio is capped at 2.
  • Progressive enhancement + reduced motion. Feature-detect WebGL; if it's missing — or the visitor prefers reduced motion — the starfield never initialises and a layered CSS radial-gradient field shows instead. The congratulations remain whole even when every moving part becomes still.

Let the moment travel

Every path is relative and there is no build, so the celebration can travel in three commands:

gh repo create afterglow-celebration --public --source . --push
gh api --method POST /repos/USER/afterglow-celebration/pages \
  -f 'source[branch]=main' -f 'source[path]=/'
# live at https://USER.github.io/afterglow-celebration/ in ~1 min

A .nojekyll file keeps Pages from touching the folder structure. The finished feeling needs no account, backend or next action.

Afterglow is a celebratory design concept. The observatories and echoes are imagined, but the dailyKpiCompleted finish is entirely yours.
